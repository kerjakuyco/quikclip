# Community conduct

Quikclip is a place for video editors and software developers of all experience levels. In issues, pull requests, and reviews:

- Ask for context before assuming what another contributor meant.
- Critique a patch or an editing workflow, not the person who proposed it.
- Respect people's privacy, including faces, voices, and file paths in footage shared for debugging.
- Do not harass, discriminate, threaten, or publish personal information without permission.

Maintainers may remove inappropriate content, close disruptive threads, or restrict participation. If you see abusive content, use the reporting menu on the GitHub comment or visit [GitHub's abuse reporting page](https://support.github.com/contact/report-abuse). Do not repost someone's private information to explain a report.
