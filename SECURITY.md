# Reporting a security issue

Use [GitHub private vulnerability reporting](https://github.com/kerjakuyco/quikclip/security/advisories/new) for issues that could expose files, run unintended commands, or affect the integrity of imported media or exports.

Include the Quikclip version or commit, your OS, the affected import or editing path, and what you observed. If a sample file is needed, describe it first rather than attaching private footage or credentials.

For ordinary playback, layout, and export bugs, use the [public issue tracker](https://github.com/kerjakuyco/quikclip/issues/new/choose).
